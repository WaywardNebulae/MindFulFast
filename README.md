# MindfulFast

A cortisol-aware intermittent fasting timer with a guided protocol for working
through the urge to eat. Installable PWA. Everything you log stays on your
device.

Live at https://waywardnebulae.github.io/MindFulFast/

- `DESIGN.md` is the design constraint set
- `RELEASE.md` covers shipping to Google Play
- `server/` is an optional push scheduler for exact alarm delivery
- `store/` holds the Play listing assets and copy

Not medical advice. See `privacy.html`.
